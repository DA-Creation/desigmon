- 순수 게임 규칙 6개 테스트: 세 시작 동료 × 100 seed, 총 300개 캠페인 모두 완료. 범위 정의 → 필요한 합의 → 제출, 저체력 시 커피를 사용하는 정책이며 모든 무작위 전략의 승리를 의미하지 않는다.

- 모바일 390×844: 초기 대화·동료 선택·터치 이동, 가로 넘침 없음. 데스크톱과 모바일 JS 오류 없음.
- ROM lab Python 9개 통과. 브라우저 출력 ROM·IPS는 Python 결과와 동일.
