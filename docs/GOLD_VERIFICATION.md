## 실행 및 제품 연결

- SameBoy `c458e7c5d2d350fb37a1931c40da9f758d28d240`의 CGB-E 코어. 자체 공개 부트 ROM, 160×144 RGBA와 48 kHz stereo PCM.
- 동일한 ROM·부트 ROM·입력·정확 RTC 모드로 native C와 WASM을 실행했다. **연속 1,200프레임의 모든 픽셀과 모든 음성 샘플이 일치**했다. 테스트 드라이버는 `tools/gold-runtime/native_verify.c`다.
- 실제 ROM 부팅, 음악 출력, 키 입력, 실행 상태 복원 후 120프레임 화면/PC 일치, 잘못된 상태 파일 거부 후 복구, SRAM 32 KiB 및 RTC 세이브 가져오기·내보내기를 검증했다.
- Node DOM 단위 테스트에서 실제 앱 핸들러와 WASM을 연결해 로드→실행→몬스터 편집→undo/redo→수정본 실행→저장/이어하기를 확인했다. Canvas는 RGBA 저장용 테스트 대역이다. 실제 브라우저의 최종 화면이나 오디오 장치 검증으로 대신 표시하지 않는다.
- 단일 HTML에 외부 CSS/JS 의존성과 원본 게임 내장이 없는지 검사했다. 브라우저 환경용 인라인 스크립트를 DOM 테스트 환경에서 직접 평가해 WASM 부팅과 프레임 진행을 확인했다. 네트워크 호출은 오류로 처리하는 테스트다.
- 개인용 HTML도 별도로 검사했다. 내장 ROM 부팅→소스 7,767개 gzip 해제→실제 WASM ASM 17회·링크 2회·헤더 처리 1회→원본 SHA-256 일치→빌드 ROM 재실행까지 네트워크 요청 없이 통과했다. `GOLD_PRIVATE_HTML`을 지정해 `tests/gold-private-source-ui.cjs`로 재현한다. 원본·소스·실행파일은 비공개 외부 경로에서만 읽는다.

## 버튼 입력으로 확인한 플레이

`tests/gold-playthrough.cjs`는 RAM·레지스터 쓰기 없이 다음 경로를 실행한다.

- 새 게임, 시계·이름 설정, 집과 어머니 이벤트, 연구소, 브케인 Lv5 획득.
- 29번도로 구구 Lv2와 전투 승리. 경험치 135→150, 남은 HP 13.
- 게임 내 레포트 저장 후 SRAM/RTC만 새 엔진에 넣고 재부팅. 모험 계속으로 파티·맵·좌표·HP·경험치 복원.
- 실행 상태 복원 후 같은 120프레임의 화면과 게임 상태 일치.
- 편집기로 브케인 기본 HP를 100, 몸통박치기 위력을 120으로 바꾼 ROM에서 같은 입력을 재실행. 실제 스타터 HP **19→25**, 같은 상대에 대한 첫 피해 **5→13** 확인.

전체 경로와 편집 비교 검증은 약 95초다. 화면/세이브/보고서는 테스트가 생성하는 저장소 밖 디렉터리에만 둔다.

## 통신 런타임

- 같은 WASM 안의 두 CGB-E를 CPU 실행 주기 단위로 동기화한다. 각 기기는 자체 ROM·화면·음성·배터리·입력을 가진다.
- 자체 제작 테스트 ROM의 CPU 프로그램으로 일반/고속 직렬 통신, 양방향 clock master, 모든 256바이트 값의 전송을 확인했다. CPU 정상/배속 혼합도 포함한다.
- 전송 중 paired snapshot을 복원해 통신 결과·시각·화면·음성 위상을 대조했다. 적외선의 실제 입력 센서 펄스도 전달·복원을 확인했다.
- 잘못된 두 번째 상태 및 외부 프레임 메타데이터는 양기기의 기존 상태를 보존한 채 거부한다. ROM 교체 중 자동 저장은 이전 ROM 슬롯에 쓰지 않는다.
- 처음부터 연결한 원본 두 기기의 1,200프레임 부팅도 검사한다. STOP 배속 전환에서 코어가 반환하는 정상적인 0주기를 가상 시간 없이 처리한다.
- DOM 단위 테스트에서 2P 부팅·화면·조작 선택·동시 진행, 통신 방식 전환, 양기기 상태 저장·복원, 2P 세이브 가져오기/내보내기를 확인했다.
- 별도 원본 실플레이에서는 알 전달 퀘스트와 포획을 거쳐 브케인 Lv8·꼬리선 Lv3 파티를 준비했다. 브케인↔꼬리선 교환, 교환실 퇴실 후 양쪽 배터리를 새 코어로 부팅해 파티 보존을 확인했다.
- 교환한 파티로 통신 대전을 실행했다. 첫 턴 몸통박치기 피해는 꼬리선 HP 15→7, 브케인 HP 25→22이며, 승패·원래 파티 HP 복구·포켓몬센터 복귀와 양쪽 0승1패/1승0패 저장을 확인했다. `tests/gold-link-playthrough.cjs`는 원본 게임 RAM 쓰기 없이 이 과정을 재현한다.

## 경계

바이트 100% 보존은 원작 전체 분기·엔딩·통신의 실기 동일성까지 모두 검증했다는 뜻이 아니다. 현재 문서의 수치만 확인된 증거로 사용한다.

upstream 명시적 링커 섹션은 53.144932%다. 나머지 영역의 원시 `db`/`ds` 표현을 고수준 역공학 완료로 취급하지 않는다. CPU/스크립트 바이트 재조립 성공도 해당 코드가 모든 실행 경로에서 올바르게 동작한다는 증명은 아니다.

빠른 필드 편집은 원래 공간 내에서 수행한다. 길이가 증가하는 변경은 소스 빌드와 뱅크/포인터 검토가 필요하다. 원본 미사용 객체의 잘못된 포인터는 원본대로 보존하고 경고로 기록한다. 실행 상태 복원 시 SameBoy가 출력 오디오 필터의 일부 이력을 재초기화하므로 복원 이후 PCM까지 동일하다고 주장하지 않는다.
