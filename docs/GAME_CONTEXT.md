# 디자인몬 어드벤처: 회수한 기획과 웹 구현

## 기준 맥락

2026-02-10에 작성·수정된 사용자 소유의 Google Docs **「디자인몬 어드벤처 게임 기획·세계관 종합 문서」**를 기준으로 한다. 문서는 기존 3D 포켓몬 실험과 별도로, 디자인 외주 경험을 이야기형 RPG에 대응시킨다. 원문 전체와 문서 내 생성 프롬프트는 저장소에 복제하지 않는다.

- 배틀 한 번 = 외주 프로젝트 한 건. 턴 = 작업과 피드백의 한 사이클.
- 승리는 클라이언트를 쓰러뜨리는 일이 아니라 기한 내 프로젝트 완수다.
- HP는 멘탈·체력·집중력, 공격은 작업물 제출, 방어는 설명·소통·논리, 속도는 작업·대응 속도다.
- 수정 요청, 일정 압박, 야근, 요구사항 변경, 번아웃이 상태이상에 대응한다.
- 클라이언트는 절대악이 아니다. 휴식·거리두기·정리는 생존 기술이다.
- 디자인몬은 야생 포획 대신 경험과 프로젝트를 통해 합류한다. 정답 파티는 없다.
- 엔딩 감정은 “조금 덜 무서워졌다”.

## 이번 구현에서 새로 정한 부분

원문에 없던 인물 이름, 마을·숲·공방의 배치, 세 개의 의뢰 줄거리, 12/12/13턴 기한, 진척 100%, 합의 목표 55/60/65, 공격·체력 수치, 아이템 가격, 경험치, 보상 및 동료 합류 순서는 **플레이 가능한 첫 챕터를 위한 구현 초안**이다. 원작 기획의 확정 수치로 간주하지 않는다.

`web/data.js`는 콘텐츠와 밸런스, `web/core.js`는 결정론적 전투·이동·저장 규칙이다. 수정·변경 방지를 미리 합의하고 설명과 제출을 섞으면 기한 안에 완수할 수 있다. 실패하면 무료 회복 후 재도전한다. 본편 의뢰 보상은 한 번만 지급하며, 숲의 연습 의뢰는 반복 가능하다.

## 구현 범위와 경계

- **독립 웹게임:** 오리지널 코드 기반 픽셀 그래픽, 네 맵, 8종, 세 의뢰와 엔딩, 16종 기술, 아이템/교체/성장/무료 회복, 브라우저 저장 및 파일 이동. ROM 없이 실행한다.
- **골드 브라우저 플레이어:** binjgb로 사용자가 선택한 실제 GB/GBC ROM을 로컬 실행한다. 입력·화면·소리·실행 상태 저장/복원을 지원한다.
- **골드 패치:** 정확히 확인한 한글 골드에서 세 종의 표시 이름과 체크섬만 변경한다. 새 이름은 타이포몽·컬러링·픽셀러다. 대사 리터럴, 닉네임, 스프라이트, 전투 규칙은 아직 원본이다.

따라서 외주 규칙을 골드 어셈블리 엔진 전체에 이식한 완성 ROM이나 3D 리메이크가 아니다. 외주 게임은 별도 웹 엔진에서 실행된다. 기획의 분기 진화·장편 세계·트레이너 비교 전투는 아직 구현 범위 밖이다.

## 골드풍 픽셀 그래픽 업데이트

탐험 화면은 실제 160×144 캔버스, 16×16 타일, 정수 배율 확대를 사용한다. 캐릭터는 16픽셀 격자에 맞춘 방향별 걷기 프레임으로 새로 그렸으며, 나무·기와·벽돌·창문·물결과 몬스터의 검은 윤곽/제한된 팔레트를 통일했다. 대화와 전투는 밝은 바탕과 검은 이중 테두리, 전투 동료 뒷모습과 픽셀 클라이언트로 변경했다. 원본 골드 그래픽을 추출해 배포한 것이 아니라 시대의 시각 문법에 맞춘 자체 픽셀 아트다.
