골드를 브라우저에서.

01 / 게임 파일

로컬 ROM 열기

원본 .gb 또는 연구실에서 만든 .gbc 파일을 선택하세요. 파일은 이 브라우저 메모리에서만 실행됩니다.

ROM 파일을 기다리고 있습니다.

02 / 이어하기

실행 상태 보관

ROM마다 별도 보관합니다. 종료 전 저장하세요. 같은 ROM을 다시 연 뒤 불러오면 이어집니다. 다른 에뮬레이터의 세이브 파일과는 호환되지 않습니다.

방향키 이동 · X 확인 · Z 취소 · Enter 시작 · Shift 선택
독립 디자인몬 게임과 별도로, 실제 골드 엔진을 실행하는 모드입니다. ROM은 포함되어 있지 않습니다. 한글 골드의 게임보이 그래픽을 그대로 실행하며 3D 변환 기능은 없습니다.
